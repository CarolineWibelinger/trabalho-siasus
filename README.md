# Trabalho 3 – - Análise de Dados do SIASUS para Apoio à Gestão Municipal de Saúde

## Descrição
Projeto desenvolvido para a atividade T3 da disciplina de Programação para Ciência de Dados. O trabalho utiliza dados do Sistema de Informações Ambulatoriais do SUS (SIASUS) para realizar consultas, análises e visualizações com SQL e Python.

## Fontes de dados
- **SIASUS – DATASUS:** dados de produção ambulatorial (PARS).
- **Base territorial:** arquivos auxiliares de municípios e regiões.

## Período analisado
- **SIASUS:** agosto de 2026.
- **Base territorial:** junho de 2026.

## Estrutura do projeto
- `sql/`: scripts de criação e preparação do banco de dados.
- `python/`: códigos de análise e visualização.
- `README.md`: informações e instruções do projeto.

## Requisitos
- MySQL Server e MySQL Workbench.
- Python 3.
- Bibliotecas Python utilizadas nas análises.

## Como executar
1. Obter os arquivos de dados nas fontes indicadas.
2. Executar os scripts SQL da pasta `sql/`, seguindo a ordem de preparação do banco.
3. Configurar a conexão com o banco de dados nos códigos Python.
4. Executar os arquivos da pasta `python/` para realizar as análises e gerar as visualizações.
